# EQUALOOM.AI - Bias and Toxicity Detector

This is a web application designed to analyze text for harmful gender bias and toxic language in real-time.

**Features:**
- Real-time classification of text as "Biased" or "Neutral".
- A confidence score visualized in a bar chart.
- A modern, responsive UI with a dark mode.

**Tech Stack:**
- **Backend:** Python, Flask, Hugging Face Transformers
- **Frontend:** HTML, CSS, JavaScript, Chart.js
